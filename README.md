# Caishen

Biological neurons trading the markets. Nothing else.*


## 📖 Overview

This is the landing page for **Caishen** – a project that uses living biological neurons to trade financial markets. Inspired by DishBrain and `doom-neuron-main`, Caishen replaces artificial neural networks with real brain cells that learn to predict and act on market data.

## 🛠 Tech Stack

| Tool          | Purpose                 |
|---------------|-------------------------|
| Vite          | Build tool & dev server |
| React 18      | UI framework            |
| Tailwind CSS  | Styling                 |
| Framer Motion | Smooth animations       |

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ and npm/yarn/pnpm

### Installation

```bash
git clone https://github.com/caishen-labs/landing-page.git
cd landing-page
npm install
npm run dev
Visit http://localhost:5173

Build
bash
npm run build
npm run preview
